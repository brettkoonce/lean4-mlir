# requirements-timm-lock.txt — the PINNED timm reference environment
#
# ⭐⭐ **THIS FILE IS A SPECIFICATION, NOT JUST A DEPENDENCY LIST.** timm is the gold standard the
# ImageNet recipes in this repo are implemented against, so "we match timm" is only a meaningful
# claim once *which* timm is written down. The version below is what every timm-diff gate compares
# against and what the recipe fidelity notes mean by "timm". Bumping it is a deliberate act that
# can turn those gates red — which is the point.
#
# Consumers:
#   scripts/randaug_timm_diff.py    RandAugment magnitude mappings vs timm's own level_to_arg
#   tests/verify_bestiary_timm.py   bestiary parameter counts vs timm's models
#   (ad hoc)                        timm.get_pretrained_cfg lookups — crop_pct, interpolation,
#                                   test_input_size, i.e. the eval protocol of appendix A
#
# ⚠⚠ **A SEPARATE ENVIRONMENT ON PURPOSE, AND THE REASON IS A REAL OUTAGE.** timm requires torch,
# and installing torch into the main `.venv` on 2026-08-14 pulled `nvidia-cudnn-cu13 9.20.0.48`,
# which installs into the SAME `nvidia/cudnn/lib/` directory as the pinned `nvidia-cudnn-cu12
# 9.23.2.1` and **overwrote it in place**. Every JAX convolution then died with
# `CUDNN_STATUS_NOT_INITIALIZED`, and `pip list` still showed both packages so the pinned version
# looked present. ▶ The torch here is the **CPU build** (`+cpu`, from
# https://download.pytorch.org/whl/cpu): zero `nvidia-*` packages, so the collision is not merely
# avoided, it is unrepresentable. Every gate above is CPU-only work, so nothing is lost.
#
# Rebuild:
#   python3 -m venv .venv-timm
#   .venv-timm/bin/pip install torch==2.13.0 torchvision==0.28.0 \
#       --index-url https://download.pytorch.org/whl/cpu
#   .venv-timm/bin/pip install -r requirements-timm-lock.txt
#
# ⚠ Install torch FIRST from the CPU index. A plain `-r` on this file resolves torch from PyPI,
# which is the CUDA build, which reintroduces exactly the problem this file exists to prevent.
# `.venv-timm/` is gitignored by the `.venv*` rule.
